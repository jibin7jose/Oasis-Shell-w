# Aegis Quarantine & Process Control

Oasis-Shell gives the AI the ability to act as a system-level Sentinel. It can monitor, suspend, resume, and completely neutralize running processes on your host OS.

## Core Capabilities & Deep Native Integration

Oasis-Shell bypasses standard command-line wrappers by integrating directly with core **Win32 APIs** and **ntdll** to achieve zero-latency hardware control.

- **Process Telemetry & Health Score**: A background thread constantly streams system telemetry, extracting CPU, RAM, Network (Up/Down in MB/s), GPU Usage (via `nvidia-smi`), and Disk availability. It calculates a real-time `health_score` by applying penalties for resource overconsumption.
- **Priority Management**: The AI can dynamically reprioritize processes (e.g., setting a background compiler to "Idle" using `SetPriorityClass`).
- **Aegis Quarantine**: A specialized security routine that forcefully terminates malicious or unwanted processes using exact PID matching.
- **Deep Process Control**: Oasis-Shell utilizes undocumented/low-level Windows APIs such as `NtSuspendProcess` and `NtResumeProcess` to instantly freeze uncooperative applications without fully killing them.
- **Productivity Analytics**: Hooks into `GetForegroundWindow` to actively track your `focus_time_seconds` per application, writing this directly into your local SQLite `app_usage_analytics` database.

## The Swarm Daemon (Autonomous Healing)

Oasis-Shell runs an active background `Swarm Daemon` that heals the OS autonomously. 
- It constantly monitors the process tree for anomalies (e.g., known memory leaks or rogue dummy processes).
- When an anomaly is detected, it instantly hatches a **Swarm-Sentinel-Alpha** Golem. 
- This Golem logs its thought trace, analyzes the threat, terminates the process, and reports that the system is healed—all without user intervention.
