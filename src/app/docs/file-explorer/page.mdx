# File Explorer

Oasis-Shell comes with an embedded, blazing-fast file explorer. It isn't just a list of files; it is fully integrated with the native AI runtime.

## Core Capabilities

- **Instant Navigation**: Navigate your directories with zero latency.
- **Smart Actions**: You can trigger Neural Macros directly on files. For example, right-clicking a `.rs` file and asking the AI to "Refactor this function."
- **Context Crates**: You can drop multiple files into a "Context Crate", which acts as a dynamic workspace. The AI will prioritize these files for subsequent logic processing.
