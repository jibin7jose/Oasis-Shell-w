# OS Architecture

Oasis-Shell is designed as a hybrid architecture built for maximum local performance and AI agency.

## The Frontend (Tauri + React)

The UI is a lightweight WebView layer managed by Tauri. It uses React and Framer Motion to deliver 120fps animations and a VS Code-like aesthetic. It communicates with the host OS purely through native Rust commands.

## The Backend (Rust)

The entire OS daemon is written in Rust for absolute memory safety and zero-overhead performance.

### The Golem Workforce
Instead of relying on a single conversational AI, Oasis-Shell splits tasks across a "Golem Workforce" (written in Rust/Tokio) that runs autonomously in the background:

1. **Autonomous Agents (Hatchery)**: You can hatch a Golem via `hatch_autonomous_golem` which traps an LLM (like `gemma4`) in a continuous background loop. It receives a mission, calculates a **Thought Trace**, and executes PowerShell commands natively. The system actively tracks the Golem's **Evolution History**, keeping a forensic record of its internal reasoning as it solves problems.
2. **Neural Workforce Panel**: An interactive UI overlay that allows you to monitor the active tasks of all hatched Golems. If a Golem generates a codebase refactor, it submits a **"Neural PR"** (Proposal). You can review the proposed changes and rationale side-by-side and click "Merge Neural PR" to execute the git integration natively via `execute_golem_manifest`.
3. **Aegis Nexus & Forensics**: A comprehensive dashboard that tracks all active Omni-Ventures. It features **P2P Neural Mirroring** (requiring Founder Vault Authentication) to sync venture state across collective nodes. Furthermore, the **Nexus Forensics AI** actively runs cross-context reasoning to detect "Synergy" (code overlaps between multiple projects) and provides economic forecasting to optimize global runway.
4. **Boardroom Debate & Advisory Consensus**: Before executing major architecture changes, the OS can convene a "Strategic Advisory Debate."
    - **4-Stage Cognitive Pipeline (`ai.rs`)**: The debate explicitly passes through 4 specialized AI personas: *The Architect* drafts the technical blueprint, *The Sentinel* audits for security vectors, *The Strategist* evaluates market momentum/ROI, and finally, *The Synthesizer* generates the merged manifest.
    - If the AI personas violently disagree on an implementation, the system requires your explicit human "Tie-breaking decision" for commit manifestation.
5. **Compute Ledger & Fiscal Audit (`health.rs`)**: Every single neural operation tracks token consumption and monetary cost inside a local `compute_ledger` table. If the AI workforce consumes too many tokens, it issues a "CRITICAL BURN" alert to protect your API budgets.
6. **Risk Simulation & Defensive Strategies (`ledger.rs`)**: During strategic planning, the AI generates "Risk Scenarios" estimating probability and impact rating, logging "Defensive Strategies" to preemptively harden the system.
7. **The Exodus Protocol (Binary Forge)**: This subsystem acts as a Native Deployment Hub. It connects directly to the underlying `rust-tauri` or `node` compilers, allowing the AI to autonomously forge standalone native application binaries (e.g., `.exe` or `.app`) or static web builds from your active ventures.
8. **Native File Explorer**: A deep OS integration that visualizes your host file system with `tauri-plugin-drag` support, full context menus, and native process launching capability without ever opening the standard Windows Explorer.
9. **Chronos State Archival (`chronos.rs`)**: A persistent background daemon that captures a literal "Chronos Snapshot" of the OS—including all UI nodes, relationships, system metrics, market intelligence, and window layouts—allowing for deterministic rollback.
10. **Storage Atlas & Relocation Engine (`reports.rs`)**: A built-in logical volume manager (`StoragePanel.tsx`). It monitors your hard drives locally, providing detailed diagnostics like capacity usage and **Encryption Toggles**. Furthermore, the AI can seamlessly execute a `relocate_foundry_storage` command, physically migrating the entire Sentient OS local database, vaults, and manifests to a new physical drive while maintaining absolute path continuity via JSON relocation maps.
11. **Cryptographic Synthesis Reports (`reports.rs`)**: Whenever the AI Boardroom reaches a critical decision, it generates a "Strategic Synthesis Report". This Markdown file is cryptographically hashed using **SHA-256** and natively archived into your local disk, ensuring that all major architectural pivots have a tamper-proof paper trail.
12. **Market Momentum Tracker (`strategy.rs`)**: The AI workforce determines `EMERALD_BIAS (Safe)` vs `RUBY_BIAS (Aggressive)` market conditions and changes its "Neural Wisdom" recommendations (Pivot vs Scale) depending on the stress/momentum of the market.
13. **3D Strategic Cortex Graph (`graph.rs`)**: Natively queries the `file_embeddings` database and runs exact cosine similarity mathematics (`cosine_similarity`) to draw dynamic 3D neural connections between your source code files based on their semantic meaning.
14. **Native Recycle Bin**: A fully custom graphical recycle bin (`RecycleBinPanel.tsx`) that manages not just standard files, but deleted AI Agents (Golems) and Context Crates, allowing you to restore them perfectly.
15. **Foundry Manual Hub**: A dynamic MDX documentation viewer built natively into the OS (`DocumentationPanel.tsx`), perfectly tracking the documentation chapters natively.
16. **Self-Modifying System Genome**: Located in `mirror.rs`, the OS possesses the ability to autonomously refactor its own source code. By analyzing target files, the local LLM calculates optimizations and proposes a **Neural Mutation**. The OS natively creates a temporary dry-run of the code, executes `cargo check` to run a forensic build audit, and if successful, marks the mutation as "Verified". Upon providing the `OASIS_FOUNDER_SECRET`, the OS will permanently apply the mutation to its own codebase.

### Artificial Intelligence Modules (`ai.rs`, `nexus.rs`, `vision.rs`, `macros.rs`, `oracle.rs`)
- **Multimodal Oracle (Omniscient Eye)**: Located in `vision.rs`, the OS natively hooks into `LLaVA` to capture base64 tensors of your active screen. By pressing a hotkey, the Oracle can provide an "executive-level strategic verdict" based purely on your visual layout and codebase structure.
- **Hardware Symbiosis**: Tied to the Oracle, if the `oracle.rs` logic detects "CRITICAL RUNWAY DEPLETION" (based on ARR and burn rate forecasting), it triggers `trigger_hardware_symbiosis`. This physically forces your machine into "Survival Mode", shifting your RGB profiles and applying a global "Grayscale Lockdown" to your display until you resolve the strategic threat.
- **Strategic Automation Forge**: Located in `macros.rs`, you can use natural language and visual contexts to generate a `StrategicMacro`. The local LLM will autonomously write both a native PowerShell script and a full topological JSON node manifest (which the frontend visualizes as a React Flow diagram).
- **Sentient Terminal & Unix Emulation**: The `TerminalPanel` doesn't just pass text; it intercepts and translates Unix/Linux commands into native PowerShell. This "Command Expansion Pack" allows you to seamlessly use `ls`, `grep`, `tail`, `touch`, `killall`, `base64`, and `zip` on Windows without installing WSL or GitBash. It also features automatic stack trace interception, where the `analyze_terminal_error` command uses the AI to diagnose and heal compilation errors dynamically.
- **Clickable Reality (Global OCR Vision)**: Accessed via `Ctrl+Shift+F`, the OS natively captures a high-fidelity screen tensor and pipes it through a localized `Tesseract.js` engine. It calculates the exact geometric bounding boxes (`BBox`) of every word on your screen, allowing you to instantly search, highlight, and copy text from unselectable elements (like images or videos) using an interactive WebGL overlay.
- **Proactive Sentience Daemon (Guardian HUD)**: A continuous background thread that monitors system telemetry and git states to offer proactive suggestions via a floating glassmorphic **Guardian Protocol** overlay. For example, if RAM exceeds 90%, it suggests crating inactive browsers. If you have >= 5 uncommitted files, it suggests a `git` diagnostic branch. It even detects weekend vs. weekday hours and suggests swapping your active "Hardware Aura" (RGB profiles/performance modes) using native PowerShell scripts. You can explicitly "Authorize" or "Dismiss" these actions.
- **Autonomous Git Commit Engine**: By analyzing the raw output of `git diff`, the AI categorizes the commit type (e.g., UI tweaks become `ui: refine component styles`, logic fixes become `fix: resolve runtime issues`) and automatically pushes the code.
- **Background File Watcher**: A native OS `notify` watcher automatically scans your `Documents`, `Downloads`, and `Desktop` folders. Any `txt`, `md`, or `ts` file added or modified is instantly parsed and embedded into your local vector database—zero clicks required.
## Technologies and Languages Used

Oasis-Shell is engineered using a combination of modern, high-performance languages and frameworks to achieve its native capabilities and seamless user interface.

### Backend (System & Core Logic)
- **Rust (Tauri Framework)**: The core OS integration, system hooks, and backend logic are written entirely in Rust. This ensures zero-overhead performance, strict memory safety, and raw speed when interfacing with the underlying operating system.
- **SQLite (Rusqlite)**: Used for embedded, hyper-fast local database storage. It seamlessly handles state management, vector data (echo memory), and configuration persistence.
- **Tokio**: The asynchronous runtime for Rust, allowing the OS daemon to handle concurrent processes, file monitoring, and background tasks efficiently without blocking.

### Frontend (User Interface)
- **TypeScript / TSX**: Provides robust end-to-end type safety for the user interface components.
- **React**: Drives the reactive, modular UI layer, rendering complex state changes instantly.
- **Tailwind CSS**: Utilized for rapid, utility-first styling to maintain the VS Code-inspired glassmorphic aesthetic.
- **Framer Motion & GSAP**: Empowers the UI with fluid, 120fps micro-animations and physics-based transitions, giving the OS a sentient, living feel.
- **Three.js & React-Force-Graph**: Handles the complex 3D visualization of the neural networks and strategic cortex directly in the WebView.

### Build & Utility
- **Vite**: The ultra-fast build tool and development server for the frontend layer.
- **PowerShell (PS1)**: Used for specialized system-level synchronization and automation scripts on Windows environments.
