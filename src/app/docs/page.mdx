# Oasis-Shell Overview

Welcome to the documentation for Oasis-Shell, the sentient AI operating system layer built with Tauri and Rust. 

## Core Features and Functions

Oasis-Shell integrates deeply with your native machine. Here is an overview of its core capabilities:

### 1. Neural Workforces & Golem Debate
Instead of a single AI, Oasis-Shell spawns distinct "Personas" (The Architect, The Strategist, The Sentinel). When you issue a complex task, these agents debate internally and synthesize a final strategic manifest for execution.

### 2. Context Crates
Your workspace states are saved into SQLite as `context_crates`. This allows the AI to automatically configure your environment based on what you were working on.

### 3. Photographic & Echo Memory
Oasis-Shell tracks clipboard history, active application telemetry, and takes visual snapshots of your workflow. This creates a persistent "memory" that the local LLM can search through natively.

### 4. Semantic Vault
All of your text files, terminal outputs, and system logs are embedded locally using VectorDB and stored in `file_embeddings`. This means your AI can instantly search your codebase entirely offline.
