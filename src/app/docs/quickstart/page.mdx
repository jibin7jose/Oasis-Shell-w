# How to Install Oasis-Shell

Welcome to the future of operating systems. Installing Oasis-Shell is straightforward and requires no complex dependencies since the AI models run entirely on your local machine using standard LLM runtimes.

## Step 1: Download the Application

You can download the compiled executable (`.exe` file) directly from our website. 

1. Click the **"Download OS"** button on the top right of the navigation bar.
2. Wait for the `Oasis-Shell-Installer.exe` to download.

*(Developer Note: To serve the .exe file from the website, place your `.exe` file into the `public/` folder of this website codebase, and rename it to `Oasis-Shell-Installer.exe`. Then the Download button will automatically serve it!)*

## Step 2: Run the Installer

1. Double click the downloaded `.exe` file.
2. If Windows SmartScreen warns you about an unrecognized app, click **More info** and then **Run anyway**.
3. Follow the setup wizard to install the application to your local disk.

## Step 3: Launch Oasis-Shell

Once installed, Oasis-Shell will run in the background. You can bring up the **Strategic Cortex** or the **Sentient Terminal** using global shortcuts at any time, across any application.

- Press `Ctrl + Space` to summon the main Neural UI.
- Type your first natural language intent, e.g., "Analyze my current window."
