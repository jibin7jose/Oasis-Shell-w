# Omni-Vent Forge & Workspace Automation

Oasis-Shell includes a powerful polyglot scaffolding engine called the **Omni-Vent Forge** and native workspace integration. It enables the AI to instantly manifest entirely new application codebases natively on your machine, manage your windows, and automate Git.

## How it works

When you issue a command like *"Create a new React project for a dashboard"*, the Architect Persona invokes the `manifest_new_venture` command.

1. **Venture Mode**: The AI decides if the request requires a web frontend (`ReactVite`) or a native desktop app (`RustTauri`).
2. **Scaffolding**: It uses native shell execution (`npx create-vite`) to physically scaffold the directory structure on your disk without you touching the terminal.
3. **Integration**: The newly created "Venture" is instantly tracked by the Oasis-Shell Sentient Vault, embedding all generated code so the AI knows exactly what was created.

### Neural Intent Commands (`Ctrl + K`)

#### Scaffolding & Neural Pitch Synthesis
- **`create [module]`** / **`architect [module]`** / **`build module [module]`**: Triggers the Architect Persona to dynamically scaffold a new module or strategic venture (e.g., `create payment gateway`).
- **Neural Forge (Blueprint Architecture)**: By invoking `manifest_architectural_blueprint` in the UI, you can provide the AI with a complex mission and multiple target files (e.g., `src/App.tsx`, `src-tauri/src/lib.rs`). The AI will synthesize the architecture and return a **"Collective Neural PR"**—a side-by-side diff showing proposed file modifications across multiple target files simultaneously. Clicking "Manifest All" automatically merges and saves the changes.
- **Visual Logic Forge**: A node-based UI (like React Flow) that allows you to drag-and-drop Triggers, Branch Logic, and Action Nodes to create visual logic chains without writing code. You can literally draw your backend architecture and click "Etch Manifest" to generate the underlying system logic.
- **Synthesis Panel (Venture Narrative)**: When planning a new architecture, the AI can generate a "Neural Pitch Synthesis." This produces a Strategic Venture Narrative and Market Correlation analysis. You can seamlessly convert this analysis into a formal "Architectural Audit" that is automatically embedded into your local Vault, or even export it as a pitch PDF directly to your desktop.
- **`sim`** / **`sandbox`**: Initiates the Strategic Venture Sandbox portal for isolated testing.

#### Workspace Context Crates & AI Telekinesis
- **`save workspace`** / **`create crate`** / **`scan workspace`**: Scans all your active applications and auto-generates a "Context Crate" saving your exact layout and active apps.
- **Context Crate Gallery**: A dedicated graphical interface (`CrateGallery.tsx`) that visually lists all your saved environments. It allows you to "Restore Environment" with a single click, view the apps contained inside the snapshot, and Export the Crate Manifests globally.
- **`launch crate`** / **`open workspace`**: Automatically launches your saved applications to restore your environment instantly.
- **`arrange`** / **`organize`** / **`snap`** / **`split`**: Triggers **AI Window Telekinesis**. By invoking `organize_workspace`, the native Rust backend leverages low-level Win32 display APIs to calculate your screen bounds and automatically snap and tile your open windows (e.g., Code on the left, Browser on the right) for optimal coding.

#### Autonomous Git Sentinel
- **`git status`** / **`review code`** / **`commit`** / **`push`**: Activating the Git Sentinel causes the AI to analyze your uncommitted changes, autonomously generate a highly contextual commit message based on the actual diffs, and push your code securely to GitHub.

#### Neural Macros (Ghost in the Machine)
- **`type [text]`** / **`press [key]`** / **`macro`**: Triggers the `execute_neural_macro` engine. This is not a simple UI wrapper; it injects native OS-level keystroke payloads (e.g., `key:win|sleep:500|text:flights to new york|sleep:800|key:enter`). The AI can physically pilot your computer, open the Start Menu, type complex queries, and navigate menus at superhuman speeds.

#### Automation Engine (Cron Jobs)
- **Scheduled Manifests**: The **AutomationPanel** provides a native cron-job interface. You can set up scheduled background tasks that trigger at specific intervals. The engine tracks the `lastRun` time, visualizes successful executions or failures, and enables one-click manual overrides to run tasks instantly.
